# RePlate frontend

See the repository root `README.md` for the complete setup and deployment guide.

Quick start:
1. Copy `.env.example` to `.env`.
2. Set `VITE_SUPABASE_URL` and `VITE_SUPABASE_PUBLISHABLE_KEY`.
3. Run `npm install` and `npm run dev`.

Never place a Supabase `service_role` key in frontend environment variables.
